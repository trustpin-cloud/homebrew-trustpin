# TrustPin Documentation

Documentation for [TrustPin](https://trustpin.cloud) developer tools distributed through this repository.

## TrustPin CLI

The official command-line interface for TrustPin certificate pinning management — manage pinning configurations, discover certificate pins, and sign and publish configurations for your mobile apps.

- **[TrustPin CLI documentation](trustpin-cli/index.md)**
  - [Command Reference](trustpin-cli/commands.md)
  - [Automation & CI/CD](trustpin-cli/automation.md)
  - [Troubleshooting](trustpin-cli/troubleshooting.md)

### Installation

```sh
brew tap trustpin-cloud/trustpin-cli
brew trust trustpin-cloud/trustpin-cli   # required once on Homebrew 6.0+
brew install trustpin-cli
```
